# Potato CLI

A secure, local-first interactive terminal file browser for Ubuntu.

Navigate directories, search files, preview contents, and inspect
file information without manually navigating through the filesystem.

## Features

- Interactive terminal interface
- Keyboard navigation
- File and directory browsing
- File search
- File previews
- Local-first operation
- Security-focused filesystem access
